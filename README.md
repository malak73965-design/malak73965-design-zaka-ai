ذكا صناعي — النسخة النهائية
نسخة واجهة واحدة تجمع:
محادثة Gemini/OpenAI مع اكتشاف نماذج Gemini تلقائيًا.
توليد صور Gemini Image وPixazo.
توليد فيديو Pixazo مع متابعة حالة المهمة تلقائيًا.
مكالمة لايف مباشرة مع Gemini باستخدام رمز مؤقت.
تحويل ردود الشات إلى صوت عبر ElevenLabs.
إرسال الرد إلى Telegram.
سجل محادثات محلي، شخصية، وضع ليلي/نهاري، وواجهة PWA.
Render
Build Command: npm install
Start Command: npm start
المتغيرات
ضع مفاتيحك الحالية في Render كما هي:
GEMINI_API_KEY
OPENAI_API_KEY
PIXAZO_API_KEY
ELEVENLABS_API_KEY
TELEGRAM_BOT_TOKEN
TELEGRAM_CHAT_ID
المتغيرات التالية اختيارية لتثبيت نماذج مخصصة:
GEMINI_MODEL / GEMINI_MODELS
OPENAI_MODEL / OPENAI_MODELS
GEMINI_IMAGE_MODEL / GEMINI_IMAGE_MODELS
GEMINI_LIVE_MODEL
PIXAZO_IMAGE_MODEL / PIXAZO_IMAGE_MODELS
ELEVENLABS_VOICE_ID
لا تضع مفاتيح API داخل ملفات public/.
